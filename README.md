# Requirements

This is to be runned on raspberry pi or similar system that has access to i2c

# Preparation

## Create venv

```
python3 -m venv .venv
```

## Activate venv

```
source .venv/bin/activate
```

## Install dependencies

```
python -m pip install -r requirements.txt
```

# Run the engine

```
python run.py
```
